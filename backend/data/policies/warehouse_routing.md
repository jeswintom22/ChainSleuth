# Warehouse Routing Policy WR-300 (Synthetic)

Document ID: WR-300. Version 1.1. Owner: Logistics Planning. Synthetic document for the ChainSleuth demonstration.

## Approved Transfer Network

Inbound shipments may only move between warehouses along transfers listed in the approved transfer network maintained by Logistics Planning. Each consecutive pair of route stops on a shipment must correspond to an approved transfer.

## Route Deviations

A shipment whose recorded route contains a transfer that is not in the approved network is a route deviation. Route deviations must be reported to Logistics Planning, which records the origin warehouse, the destination warehouse, the shipment and the stop sequence. A route deviation is reviewed together with any delivery or invoicing exception on the same purchase order.

## Emergency Re-routing

Emergency re-routing is allowed only with a recorded authorisation reference. Authorised emergency transfers should be added to the shipment record so that they are not reported as deviations.
